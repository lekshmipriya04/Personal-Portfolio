ML · Deep Learning
Malayalam Handwritten Character Recognition using KAN
A handwritten character recognition system for Malayalam script that replaces the conventional MLP classification head with a Kolmogorov-Arnold Network (KAN), whose learnable spline-based edge activations are better suited to distinguishing the script's visually similar, curvilinear characters. Built on a lightweight depthwise-separable CNN backbone with residual and squeeze-and-excitation attention, the model classifies 119 character classes with 82.72% test accuracy. A controlled ablation study confirmed the KAN head consistently outperforms a standard linear head under identical training conditions. Presented as a research paper at ICCMMAI 2026, Bharata Mata College (Autonomous).
